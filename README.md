# portfolio

Mi portfolio: una colina con cinco proyectos, cada uno con su personaje.
Se publica en https://martinvainstein.ar con GitHub Pages.

- Todo vive en `index.html` (HTML, CSS y JavaScript a mano, sin build); las imágenes, en `img/`.
- `CNAME` le dice a GitHub Pages qué dominio usar.
- Para verlo en local: `python3 -m http.server 8000` y abrir http://localhost:8000.
